# 🎓 Student Placement Prediction using Machine Learning

## 📌 Project Overview

This is a beginner-friendly Machine Learning project that predicts whether a student is likely to get placed based on academic performance, skills, and other career-related factors.

The model is trained using a student dataset and then used to make predictions for new student data.

## 🎯 Objectives

- Understand the fundamentals of Machine Learning.
- Prepare and organize a student dataset.
- Train and test a Machine Learning model.
- Predict placement outcomes for new student data.
- Learn the basic Machine Learning workflow.

## 📊 Dataset Features

The model uses the following input features:

- CGPA: Academic performance.
- Skills: Skill score.
- Projects: Project score or count.
- Internships: Number of internships.
- Certifications: Number of certifications.
- DSA Score: Data Structures and Algorithms score.

**Target variable:** `Placed` — `1` indicates placed, and `0` indicates not placed.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## ⚙️ Project Workflow

1. Import the required libraries.
2. Create and prepare the dataset.
3. Separate features (`X`) and target (`y`).
4. Split the dataset into training and testing sets.
5. Train the Machine Learning model.
6. Test the model.
7. Enter new student data.
8. Display the placement prediction.

## ▶️ How to Run

1. Open the `.ipynb` notebook in Google Colab.
2. Execute the notebook cells in order.
3. Train the model using the dataset.
4. Provide the details of a new student.
5. View the prediction output.

## 📌 Sample Output

- `PLACED` ✅
- `NOT PLACED` ❌

*Note: Predictions depend on the dataset and model. This project is intended for educational purposes and should not be used for real recruitment decisions.*

## 📚 Key Learnings

- Dataset preparation and feature selection.
- Training and testing a Machine Learning model.
- Making predictions on new data.
- Understanding an end-to-end Machine Learning workflow.
